# 资源运行时验收

重启客户端后进入允许命令的测试世界，执行 `/ysa reload`。本轮新增资源余额、恢复/衰减与同步，不绘制 HUD，也不改变原版生命与伤害。

## 查询、恢复和界限

```text
/ysa resource @s "精力"
/ysa resource @s "精力" set 0
/ysa resource @s "精力"
```

默认上限 500，恢复 40/秒。set 输出为 0，保持游戏运行几秒后再查询应看到每 20 个服务器 tick 增加 40；约 13 秒补满，不能超过 500。菜单暂停期间不会恢复。

```text
/ysa resource @s "集中" set 0
/ysa resource @s "充能" set 30
/ysa resource @s "充能" add 80
/ysa resource @s "充能" add -200
```

集中恢复 10/秒，上限 100。充能默认衰减 0，以上输出依次为 30、100、0。

## Molang 与存档

```text
/ysa resource @s "充能" set 37
/ysa attr @s "充能值"
/ysmclient molang execute ysa.attr('充能值')
```

两处读数均应为 37。正常退出世界、重新进入、切换维度、测试世界死亡重生后仍应是 37。

`ysa.attr('精力值')`、`ysa.attr('精力上限')`、`ysa.attr('精力恢复速度')` 分别读取当前值、上限和恢复参数。Molang 返回 float，可能有舍入误差；测试时确保 YSM 调试目标是自己。

## 角色参数和 reload

```text
/ysa role @s "示例战士" 1
/ysa resource @s "法力"
/ysa level @s 10
/ysa resource @s "法力"
```

默认模板 1 级法力上限 32.76、恢复 7.245/秒；10 级上限 46.8、恢复 10.35/秒。角色变更保留余额，不自动补满。尚未选角色时法力上限可能为 0，后续选角色会逐步恢复。

备份 formulas.yml 后，将充能衰减速度临时改成 `"5"`，reload 并设置充能为 50；之后每秒应减少 5，最低 0。再将充能上限改为 `"20"` 并 reload，应把现有余额截断到 20 以内。增加上限不会补充余额。

将精力上限临时改为 `"-1"`，reload 应在聊天框提示资源错误，仍使用原来的有效配置与余额（正常恢复/衰减继续运行）。测试完恢复备份并 reload。
